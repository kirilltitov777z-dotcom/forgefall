# Forgefall

Игра в духе **Mindustry** — фабрика + башневая оборона, но со своей структурой и
**земной, природной палитрой вместо неона** (песок, глина, камень, дерево, ржавчина).

Проект целиком собирается в APK через **GitHub Actions** — без локального Android SDK.

## Что это

- Сетчатый мир 48x48, руды меди и железа, скалы.
- **Бур** добывает руду и кладёт её на конвейер.
- **Конвейер** двигает предметы в направлении стрелки.
- **Турель** стреляет по врагам, расходуя медь как боеприпас.
- **Стена** блокирует врагов.
- **Ядро** в центре — если его уничтожат, игра окончена.
- Волны врагов (пехота, бегуны, танки) нарастают со временем.

## Управление

- Нижний ряд кнопок: выбор постройки (Бур / Лента / Турель / Стена), Удаление, Поворот.
- **Тап** по полю — поставить выбранное здание / удалить (режим «Удал.»).
- **Тяни пальцем** — двигать камеру.
- **Два пальца** — масштабирование.

## Сборка APK

1. Сделай `git push` в ветку `main` (или `master`), либо запусти workflow вручную
   (вкладка **Actions → Build Forgefall APK → Run workflow**).
2. Дождись окончания сборки.
3. Открой последний run → **Artifacts** → `forgefall-debug-apk` → скачай и распакуй.
4. Установи `app-debug.apk` на телефон (нужно разрешить установку из неизвестных источников).

Workflow находится в `.github/workflows/build.yml`. Он ставит JDK 17, Android SDK,
Gradle 8.4 и выполняет `gradle assembleDebug`.

## Структура

```
app/src/main/java/com/forgefall/game/
  MainActivity.java   — точка входа
  Game.java           — симуляция: мир, здания, враги, волны, ресурсы
  GameView.java       — отрисовка, камера, ввод, игровой цикл
```

## Технологии

Java 17, Android Gradle Plugin 8.3, compileSdk 34, minSdk 21. Никаких внешних
зависимостей, только платформенные API — чтобы сборка в облаке была максимально
надёжной и быстрой.
